MundicoArquitetura e capacidades
Documento técnico · Groq + ferramentas determinísticas

O modelo orquestra.
Nunca é a fonte do número.

Como Mundico é montada: inferência rápida no Groq para entender a pergunta e escolher a ferramenta, e código determinístico nosso para produzir todo dado, todo documento e todo protocolo.

01 · Arquitetura

Onde o modelo entra — e onde ele é proibido de entrar.

O desenho tem uma única regra estrutural: o LLM só vê dados que vieram das nossas funções, e o texto de saída é montado sobre esses retornos. Se a ferramenta não devolveu, Mundico não afirma.

Por que Groq

Latência de conversa

A inferência em LPU responde em fração de segundo. Num painel, o assistente que demora 6 s não é usado — a velocidade aqui é requisito de produto, não vaidade técnica.

Modelo

Aberto e substituível

Usar um modelo aberto servido pelo Groq (família Llama) com function calling. A camada de ferramentas é agnóstica: trocar de provedor não muda a lógica de negócio.

Custo e sigilo

Contexto mínimo

Não se envia a base ao modelo — só a pergunta, o ente aberto e o retorno da chamada. Contexto pequeno significa resposta barata, rápida e sem vazar acervo.

Regra de permissão

Leitura executa sem perguntar. Confirmar mostra o que será feito e espera um clique. Confirmação dupla exibe destinatário e conteúdo integral antes de liberar o envio — nenhuma peça sai do sistema sem que uma pessoa tenha visto exatamente o que vai sair.

03 · Contrato de ferramenta

Como uma capacidade é declarada.

O modelo recebe apenas a assinatura. A execução, a validação e a citação da fonte ficam do nosso lado.

// Declaração enviada ao Groq — o modelo escolhe, não executa.
{
  name: "buscarReferencia",
  description: "Entes avaliados como 'Estágio avançado' no mesmo requisito, " +
               "com a prática que a auditoria registrou.",
  parameters: {
    requisito: "código do item, ex.: P5A",
    excluir:   "ente a omitir da lista (o próprio consultado)"
  }
}

// Retorno do nosso lado — sempre com procedência anexada.
{
  referencias: [
    { ente: "Minas Gerais", tipo: "Estado", texto: "..." }
  ],
  fonte: {
    base:      "Painel ClimaBrasil / TCU",
    versao:    "Versão de Avaliação 2025",
    extracao:  "2025-09-12",
    requisito: "P5A"
  }
}
Instrução de sistema — a linha que não se negocia

“Você responde exclusivamente com dados retornados pelas ferramentas. Se a informação não estiver no retorno, diga que não sabe e ofereça a consulta adequada. Nunca estime, complete ou infira números. Toda afirmação quantitativa deve vir acompanhada do campo fonte recebido. Nunca afirme relação de causa e efeito entre lacuna e desastre.”

04 · Fluxos de automação

Três rotinas que devolvem tempo ao gestor.

O ganho real não é conversar — é encurtar o caminho entre perceber um problema e ter a peça pronta na mão.

Rotina 1 · sob demanda

Da pergunta ao ofício

“Gera o ofício das lacunas de defesa civil.” Mundico prioriza, monta a peça com protocolo, mostra na tela e espera confirmação para enviar. O que levava uma tarde de compilação vira um minuto.

Rotina 2 · periódica

Vigília de safra

Quando o Painel publica nova avaliação, Mundico compara com a anterior e avisa o que mudou nos requisitos monitorados — inclusive o que não mudou depois de um encaminhamento.

Rotina 3 · agregada

Boletim do território

Recorte por região ou porte, com os requisitos mais frágeis do grupo. Serve a associações de municípios e a tribunais estaduais que acompanham várias jurisdições.
